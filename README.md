# pane 0.6.0

Windows 다중 패널 파일 탐색기와 SSH/SFTP 작업 공간입니다.

## 이번 버전

0.5.0에서 추가했던 탐색기 확장(시스템 클립보드, 덮어쓰기·병합, 실행 취소·일시정지, Windows 셸 메뉴, 트리·미리보기·ZIP, 추가 작업 공간·다중 탭)을 제거하고 탐색기는 0.4.0 동작으로 되돌렸습니다.

기존 탐색기의 복사·이동, 이름 변경, 휴지통, 즐겨찾기, 패널 분할은 유지합니다.

## SSH / SFTP

1. 왼쪽 **SSH / SFTP** 메뉴를 선택합니다.
2. **SSH 연결**을 누르고 호스트 주소 또는 `~/.ssh/config`의 Host 별칭을 입력합니다.
3. 사용자 이름과 포트는 비워두면 OpenSSH 설정을 사용합니다. 기본 인증은 자동입니다.
4. 연결하면 왼쪽부터 **로컬 파일 → 원격 파일 → SSH 터미널**이 표시됩니다.
5. 파일·폴더를 선택한 뒤 업로드 또는 다운로드를 누릅니다. 대상은 반대편 패널의 현재 폴더입니다. 폴더 이름을 누르면 이동하고 주소 입력이나 상위 폴더 버튼도 사용할 수 있습니다.
6. 터미널은 실제 SSH PTY입니다. 셸 명령, 방향키, Ctrl+C, 대화형 프로그램을 사용할 수 있습니다. 셸이 종료되면 **셸 다시 열기**로 재실행합니다.

### 기존 키 사용

- Windows OpenSSH의 `ssh -G`로 HostName, User, Port, IdentityFile, IdentityAgent, IdentitiesOnly 설정을 해석합니다.
- 자동 인증은 SSH 에이전트와 설정된 키·기본 키를 사용합니다. 별도의 비밀번호 입력이 필수는 아닙니다.
- 서버에 배포한 공개키와 짝이 되는 개인키가 이 PC에 있어야 합니다. 암호화된 개인키는 에이전트에 등록하거나 연결 폼에 키 암호를 입력합니다.
- 직접 키를 지정하려면 인증 방식에서 **개인키 직접 선택**을 사용합니다.
- 기존 OpenSSH `known_hosts`(해시 호스트명 포함)를 참조합니다. 처음 보는 서버만 지문 확인을 요청하며 변경되거나 폐기된 키는 차단합니다.
- 비밀번호·키 암호·개인키 내용은 앱 설정에 저장하지 않습니다.

### 글자 크기

상단 **글자 크기**에서 11~20px를 선택합니다. 탐색기와 터미널 모두 반영되며 다음 실행에도 유지됩니다.

### 범위와 제한

- 현재 SSH 연결은 하나이며 직접 연결을 지원합니다. ProxyJump/ProxyCommand, X11, 키보드 대화형 MFA는 지원하지 않습니다.
- 원격 파일 패널과 셸의 현재 경로는 각각 유지됩니다.
- SFTP는 기존 파일을 덮어쓰지 않습니다. 심볼릭 링크는 전송하지 않으며 전송 실패 시 일부 대상이 남을 수 있습니다.
- SFTP 전송 중에는 연결 종료·폴더 이동이 잠기며 앱 종료는 파일 작업 완료를 기다립니다.
- 0.5 세션 중 기존 두 작업 공간의 경로는 읽을 수 있지만 추가 작업 공간과 탭은 제거됩니다.

## 개발

Windows, Node.js 24 LTS, OpenSSH 클라이언트가 필요합니다.

```powershell
npm ci
npm run check
npm test
npm run desktop
npm run build:portable
```

빌드 결과: `dist-portable/pane-0.6.0-portable-x64.exe`.
개발 및 테스트 방법은 [CONTRIBUTING.md](CONTRIBUTING.md), 검증 내역은 [VERIFICATION-0.6.md](VERIFICATION-0.6.md)를 참고하세요. 이전 VERIFICATION 문서는 해당 과거 버전 기록입니다.
