# pane

Windows의 실제 드라이브와 폴더를 나란히 탐색하고, 여러 패널 사이에서 파일을 복사·이동하는 멀티패널 파일 탐색기입니다. 현재 버전은 `0.4.0`입니다.

소스 기준 갱신: 2026-09-14

## Windows 포터블 실행

빌드 결과인 `dist-portable/pane-0.4.0-portable-x64.exe`를 쓰기 가능한 폴더에 두고 실행합니다. 설치, 관리자 권한, 별도 Node.js가 필요하지 않습니다.

열린 폴더와 작업 공간은 실행 파일 옆 `pane-data/session.json`, 사용자 즐겨찾기와 최근 경로는 `pane-data/preferences.json`에 저장합니다. 테마도 같은 `pane-data/` 안에 보관하므로 앱을 옮길 때 이 폴더를 함께 옮깁니다. 자세한 내용은 [PORTABLE.md](PORTABLE.md)를 참고합니다.

## 탐색과 즐겨찾기

- 이 PC의 드라이브와 홈·바탕 화면·다운로드·문서·사진 폴더 탐색
- 패널별 전체 경로 입력 후 `Enter`로 이동. 드라이브 경로와 UNC 공유 폴더 경로 지원
- 주소창의 펼침 버튼에서 현재·상위 폴더, 즐겨찾기, 최근 경로, 드라이브 선택
- 즐겨찾기 옆 `＋`로 현재 폴더 추가. 직접 추가한 폴더는 옆의 제거 버튼으로 삭제
- 폴더 두 번 클릭, 뒤로·상위 폴더 이동, 새로고침
- 1·2·4분할, 현재 패널 확대, 두 작업 공간 전환
- 열린 폴더의 항목 이름 검색, 파일명·수정일·크기 정렬
- 작업 공간과 패널별 경로·정렬·분할·활성 패널, 즐겨찾기·최근 경로·테마를 재실행 후 복원

파일 두 번 클릭 또는 `Enter`는 Windows에 연결된 기본 앱으로 파일을 엽니다. 종류·크기·수정일·전체 경로는 **파일 정보** 또는 `Alt+Enter`로 확인합니다. 검색은 열린 폴더의 항목만 필터링하며 하위 폴더를 재귀 검색하지 않습니다.

## 오른쪽 클릭과 파일 관리

파일·폴더를 오른쪽 클릭하면 열기, 잘라내기·복사·붙여넣기, 다른 창으로, 이름 변경, 삭제, 탐색기에서 보기, 파일 정보를 제공합니다. 이미 선택한 항목에서 메뉴를 열면 여러 항목 선택이 유지됩니다. 빈 공간에서는 새 폴더, 붙여넣기, 새로고침, 모두 선택, 탐색기에서 보기를 제공합니다. 키보드는 `Shift+F10` 또는 메뉴 키를 사용합니다.

- `F2`: 선택한 항목 하나의 이름 변경. 기존 이름과 충돌하거나 Windows에서 쓸 수 없는 이름이면 오류를 표시합니다.
- `Ctrl+Shift+N`: 현재 패널의 폴더 안에 새 폴더 생성.
- `Delete`: 선택한 항목을 확인한 뒤 Windows 휴지통으로 이동. 확인 창의 처음 포커스는 **취소**이며, 취소하거나 `Escape`로 닫으면 파일을 변경하지 않습니다.
- **탐색기에서 보기**: 항목 또는 현재 폴더를 Windows 탐색기에서 표시.

오른쪽 클릭 메뉴는 pane의 기본 작업 메뉴입니다. Windows 셸 확장 메뉴는 포함하지 않습니다. 영구 삭제는 제공하지 않으며, 휴지통으로 보낼 수 없는 항목은 실패로 알리고 영구 삭제로 대체하지 않습니다. 이미 시작한 파일 작업을 중단하는 기능은 없습니다.

## 파일 복사와 이동

1. 파일 목록에서 항목을 선택합니다. `Ctrl+클릭`은 개별 선택, `Shift+클릭`은 범위 선택, `Ctrl+A`는 표시된 항목 전체 선택입니다.
2. `Ctrl+C`로 복사 또는 `Ctrl+X`로 이동을 준비합니다.
3. 대상 패널을 선택하고 `Ctrl+V`로 실행합니다. 다른 작업 공간으로 전환해도 준비한 항목은 유지됩니다.

툴바의 **다른 창으로** 버튼에서는 다른 작업 공간을 포함한 열린 폴더를 고른 뒤 복사·이동을 실행할 수 있습니다. 폴더 안의 하위 항목과 서로 다른 드라이브 사이의 작업도 지원합니다. 폴더 항목의 오른쪽 클릭 메뉴에서 **붙여넣기**를 선택하면 그 폴더 안으로 보냅니다. 복사·이동 대기 목록은 pane 앱 안에서만 사용하며 Windows 클립보드와 공유하지 않고 재실행 시 초기화됩니다.

선택한 항목을 다른 패널의 파일 목록이나 폴더 항목으로 끌어 놓을 수도 있습니다. 기본 동작은 같은 드라이브에서 이동, 다른 드라이브에서 복사입니다. UNC 경로는 같은 공유 루트를 기준으로 판단합니다. `Ctrl`을 누르면 복사, `Shift`를 누르면 이동하며 대상 폴더와 작업을 화면에 표시합니다.

Windows 탐색기에서 실제 파일·폴더를 끌어오는 경로도 지원합니다. 외부 드롭은 실제 파일 객체에서 경로를 얻으며 문자열로 전달된 경로는 받지 않습니다. pane에서 다른 앱으로 끌어낼 때는 `Alt`를 누른 채 드래그를 시작합니다. 외부 앱으로의 실제 마우스 드롭 완료는 아직 수동 검증하지 않았습니다.

같은 이름의 대상 항목은 덮어쓰거나 폴더를 병합하지 않고 건너뜁니다. 링크·정션이 포함된 경로, 자기 폴더의 하위로 보내는 작업, 드라이브·공유 루트 전체 작업은 처리하지 않습니다. 결과에는 완료·건너뜀·실패 항목이 구분되며, 이동이 일부만 끝났으면 확인할 원본·대상 경로를 표시합니다.

툴바 아래의 고정 높이 작업 상태 줄에서 복사 대기·진행·저장 상태를 확인합니다. **작업 결과**를 누르면 상세 결과가 겹쳐 열립니다. 파일 작업이나 결과 표시가 창과 패널의 크기를 자동으로 바꾸지 않습니다.

## 단축키

| 단축키 | 동작 |
| --- | --- |
| `Ctrl+L` / `Ctrl+K` | 현재 주소창 선택 / 열린 폴더 검색 |
| 주소창에서 `Alt+↓` | 경로 목록 열기 |
| `Alt+←` / `Alt+↑` | 이전 폴더 / 상위 폴더 |
| `F5` | 현재 패널 새로고침 |
| `Ctrl+A` | 목록에서 표시된 항목 전체 선택 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 복사 준비 / 이동 준비 / 붙여넣기 |
| `Enter` | 주소 적용 또는 폴더·기본 앱에서 파일 열기 |
| `Alt+Enter` | 파일 정보 보기 |
| `Shift+F10` / 메뉴 키 | 파일 또는 빈 공간의 작업 메뉴 열기 |
| `F2` / `Ctrl+Shift+N` | 이름 변경 / 새 폴더 |
| `Delete` | 확인 후 휴지통으로 이동 |
| 드래그 중 `Ctrl` / `Shift` | 복사 / 이동 지정 |
| `Alt`를 누른 채 드래그 시작 | 다른 앱으로 파일 끌어내기 |
| `↑` / `↓` / `Home` / `End` | 목록 항목 이동 |
| `Escape` | 메뉴·작업 결과·대화상자 닫기, 주소 편집·검색·복사 대기 취소 |

읽을 수 없는 폴더는 해당 패널에 오류와 재시도를 표시합니다. 재실행 시 사라진 폴더도 저장된 경로를 유지합니다.

## 개발과 검증

Node.js와 npm이 설치된 프로젝트 폴더에서 실행합니다.

```powershell
npm ci
npm run desktop
```

| 명령 | 용도 |
| --- | --- |
| `npm start` | 루프백 웹 서버 실행 |
| `npm run desktop` | Electron 앱 개발 실행 |
| `npm run check` | 렌더러·데스크톱 JavaScript 문법 검사 |
| `npm test` | 파일 조회·복사·이동·탐색기 작업과 세션·즐겨찾기 저장 테스트 |
| `npm run build:portable` | Windows x64 포터블 EXE 생성 |

`npm start` 후 `http://127.0.0.1:4173`에서 화면을 확인할 수 있습니다. 일반 브라우저에서는 포터블 앱 실행 안내를 표시합니다. 다른 포트는 `$env:PORT = '4174'`로 지정하고, 서버는 `Ctrl+C`로 종료합니다.

빌드 후 별도로 제공된 Playwright 의존성 경로로 검증을 실행할 수 있습니다. 앱 자체에는 Playwright가 필요하지 않습니다.

```powershell
node .checks/verify-real-files.cjs 'Playwright가 들어 있는 node_modules의 절대 경로'
node .checks/verify-workflows.cjs 'Playwright가 들어 있는 node_modules의 절대 경로'
node .checks/verify-explorer.cjs 'Playwright가 들어 있는 node_modules의 절대 경로' --mouse-drag
node desktop/verify-launcher.cjs 'Playwright가 들어 있는 node_modules의 절대 경로'
```

`verify-explorer.cjs`는 메뉴·이름 변경·새 폴더·휴지통·드롭과 작업 전후 화면 크기를 검사합니다. 기본 앱 열기·탐색기 표시·외부 드래그는 Electron 호출을 가로채므로 실제 외부 앱 동작을 검증하지 않습니다. 위 명령은 실행 방법이며, 확인된 검증 결과와 한계는 [VERIFICATION.md](VERIFICATION.md), 화면 구성은 [DESIGN.md](DESIGN.md)에 있습니다.
