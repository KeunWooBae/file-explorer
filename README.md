# pane 0.6.1

Windows 다중 패널 파일 탐색기와 SSH/SFTP·Multi-Execution 작업 공간입니다. 이번 변경은 `0.6.0 → 0.6.1` 패치 버전으로 관리합니다.

## SSH / SFTP

왼쪽 아이콘이 있는 **SSH / SFTP** 메뉴에서 **SSH 연결**을 누릅니다. 호스트 주소 또는 OpenSSH Host 별칭을 입력하고, 사용자·포트는 비워두면 OpenSSH 설정값을 사용합니다. 연결하면 로컬 파일, 원격 파일, SSH 터미널이 나란히 표시됩니다.

인증 방식은 두 가지만 제공합니다.

- **비밀번호**: 원격 계정 비밀번호 입력.
- **개인키 자동 식별 (기본 .ssh 폴더)**: 이 PC 사용자 홈의 `.ssh` 폴더에서 개인키를 찾습니다. 기본 이름 `id_ed25519`, `id_rsa`, `id_ecdsa`를 우선 시도하고 다른 이름의 키도 검사합니다. 암호화된 키는 키 암호를 입력합니다. 에이전트·직접 키 파일 선택은 제공하지 않습니다. 폴더 밖의 IdentityFile은 사용하지 않습니다.

기존 `known_hosts`를 참조하고 새로운 서버만 지문을 확인합니다. 변경·폐기된 서버 키는 차단합니다.

### Follow terminal folder

터미널 아래 **Follow terminal folder**를 켜면 Bash/Zsh에서 명령 완료 후 보고한 실제 현재 경로로 원격 파일 패널이 이동합니다. `cd`, `cd ..`, 별칭·함수로 이동한 경로도 프롬프트에서 보고된 위치를 따릅니다. 끄면 원격 파일 패널의 폴더를 독립적으로 탐색할 수 있습니다. 선택은 재실행 후 유지됩니다.

셸 시작 시 해당 프로세스에만 프롬프트 훅을 설치하며 `.bashrc`·`.zshrc` 같은 원격 파일은 수정하지 않습니다. Bash/Zsh 이외의 셸, 중첩된 SSH 접속이나 별도 셸·tmux 내부의 경로는 자동 추적 대상이 아닙니다. 실행 중인 프로그램에 옵션 변경용 명령을 입력하지 않습니다.

### 저장 세션

0.6.1부터 연결 성공 시 호스트·포트·사용자·인증 방식·세션 이름이 자동 저장됩니다. 연결 폼의 **저장된 세션**에서 다시 선택하거나 삭제할 수 있습니다. **비밀번호·개인키 내용·키 암호는 저장하지 않습니다.** 비밀번호 연결은 다시 열 때 비밀번호를 입력합니다.

설정은 실행 파일 옆 `pane-data/ssh-sessions.json`에 저장되며 개발 중에는 `.pane-dev-data`를 사용합니다. 최대 100개 세션을 저장할 수 있습니다.

## Multi-Execution Terminal

1. 왼쪽 **Multi-Execution Terminal** 메뉴를 엽니다.
2. 저장된 세션을 체크하고 **선택한 세션 열기**를 누릅니다. 최대 12개 터미널을 열 수 있습니다.
3. 하단 공통 명령 입력란에 명령을 적고 **명령 동시 실행**을 누릅니다.
4. 터미널 아래 **동시 명령 제외**를 체크하면 해당 터미널은 공통 명령을 받지 않습니다. 개별 터미널에 직접 입력하는 것은 가능합니다.
5. **파일 선택 / 폴더 선택** 후 각 터미널의 **파일 전송 대상**과 **파일 대상 폴더**를 확인하고 전송합니다. 호스트마다 목적지를 다르게 지정할 수 있습니다.

동시 명령 제외와 파일 전송 대상은 독립된 설정입니다. 파일 전송은 기존 파일을 덮어쓰지 않으며 성공·실패를 각 터미널 아래에 표시합니다. 원격 대상 폴더는 미리 존재해야 합니다. 심볼릭 링크는 전송하지 않습니다. 전송 실패 시 부분 대상이 남을 수 있으며 원본은 유지됩니다.

## 기본 탐색기와 글자 크기

기본 탐색기는 기존 0.4 기반 동작을 유지합니다. 상단 **글자 크기**로 탐색기와 모든 SSH 터미널의 글자를 조절하고 저장합니다.

## 개발과 빌드

Windows, Node.js 24 LTS, OpenSSH 클라이언트가 필요합니다.

```powershell
npm ci
npm run check
npm test
npm run desktop
npm run build:portable
```

실행 파일: `dist-portable/pane-0.6.1-portable-x64.exe`.
협업은 [CONTRIBUTING.md](CONTRIBUTING.md), 검증은 [VERIFICATION-0.6.1.md](VERIFICATION-0.6.1.md)를 참고하세요.

현재 직접 SSH 연결을 지원하며 ProxyJump/ProxyCommand, X11, 키보드 대화형 MFA는 포함하지 않습니다. 과거 VERIFICATION 문서는 해당 버전의 기록입니다.
