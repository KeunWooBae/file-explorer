# pane 0.5.0

Windows 멀티패널 파일 탐색기. 실제 로컬 파일 관리와 SSH/SFTP 파일 전송을 지원합니다.

## 실행

`dist-portable/pane-0.5.0-portable-x64.exe`를 쓰기 가능한 폴더에서 실행하세요. 설치와 관리자 권한은 필요하지 않습니다. 실행 파일 옆의 `pane-data`에는 작업 공간·탭·즐겨찾기·테마·신뢰한 SSH 서버 키를 저장합니다. 앱을 옮길 때 함께 옮기세요.

## 파일 탐색과 작업 공간

- 1·2·4분할, 활성 패널 확대, 패널별 경로 입력·뒤로·상위 이동
- 패널 제목의 `＋`로 탭 추가, `×`로 현재 탭 닫기: 패널당 최대 20개
- **기능 → 작업 공간 추가 / 작업 공간 이름 변경**: 작업 공간 최대 20개
- 즐겨찾기·최근 경로, 이름·날짜·크기 정렬, 열린 목록 이름 검색
- 큰 폴더의 목록 가상화, 표시 중인 패널 우선 조회, 동시 중복 조회 공유
- 외부 파일 변경 감지, 창 복귀 시 폴더·드라이브 갱신
- 작업 공간·탭·경로·정렬 복원, 순서가 보장되는 비동기 세션 저장

네트워크 폴더 등 변경 알림을 지원하지 않는 위치에서는 창 복귀 또는 `F5`로 갱신합니다. 검색은 하위 폴더 재귀 검색이 아닙니다.

## 복사·이동·실행 취소

`Ctrl+C / Ctrl+X / Ctrl+V`와 Windows 파일 클립보드를 사용합니다. Windows 탐색기와도 파일 복사·붙여넣기가 가능합니다. 여러 항목은 Ctrl/Shift 클릭으로 선택합니다. 패널 간 드래그와 폴더 행으로의 드롭도 지원합니다.

**기능 → 파일 충돌 처리**에서 이번 실행의 정책을 선택합니다.

1. 같은 이름 건너뛰기 — 기본값
2. 기존 항목 백업 후 교체
3. 폴더 병합 · 같은 파일 건너뛰기
4. 폴더 병합 · 같은 파일 백업 후 교체

복사는 임시 위치에서 완료한 뒤 공개합니다. 파일의 NTFS 추가 스트림과 파일·폴더 수정 날짜를 보존합니다. 링크·정션과 드라이브 루트 변경은 제한합니다.

상태 줄의 **일시정지 / 계속 / 취소**는 현재 파일이 끝난 뒤 적용됩니다. 진행 바이트·비율·평균 속도를 표시합니다. 같은 드라이브의 네이티브 이동은 바이트 복사가 없어 진행 수치가 복사와 다릅니다.

**실행 취소 / Ctrl+Z**는 이번 실행에서 수행한 복사·이동·이름 변경·새 폴더 작업을 역순으로 되돌립니다. 변경된 대상이나 원래 위치의 충돌이 있으면 중단합니다. 휴지통·Windows 메뉴·ZIP 추출·SFTP 전송은 이 기록에 포함하지 않습니다.

교체한 기존 항목은 대상 폴더의 `.pane-undo-…`에 보관하며, 옆 JSON 파일에 원래 경로를 기록합니다. 실행 취소로 복원하면 해당 기록을 정리합니다. 재실행 후 자동 실행 취소 기록은 유지되지 않지만 백업과 경로 기록은 남습니다. 필요한 백업을 확인한 뒤 직접 정리할 수 있습니다.

## 추가 탐색 도구

**기능** 버튼에서 다음 도구를 엽니다.

- **폴더 트리**: 현재 폴더의 하위 폴더를 펼쳐 탐색
- **선택 파일 미리보기**: 텍스트·소스 코드(처음 256 KB), PNG/JPEG/GIF/WebP/BMP(12 MB 이하)
- **ZIP 탐색**: 내부 경로 검색, 개별 파일을 현재 폴더에 추출. 기존 파일은 덮어쓰지 않으며 파일당 1 GB 제한
- **Windows 메뉴**: 선택 항목의 실제 Windows 셸 메뉴. 선택하지 않으면 현재 폴더의 항목 메뉴
- **간결한 화면 전환**: 상단 제목 영역을 줄여 파일 목록 공간 확보

Windows 메뉴는 별도 STA 프로세스에서 `IContextMenu`와 하위 메뉴 메시지를 처리합니다. 셸 확장이 수행하는 작업은 Windows가 관리합니다. 모든 제3자 확장의 실제 명령 동작을 검증한 것은 아닙니다.

## SSH / SFTP

1. 다운로드를 받을 로컬 폴더를 패널에서 엽니다. 업로드하려면 로컬 파일·폴더를 먼저 선택합니다.
2. 상단 **SSH / SFTP**를 누릅니다.
3. 호스트·포트·사용자와 비밀번호 또는 개인키 파일 경로를 입력하고 연결합니다.
4. 처음 연결 시 표시되는 SHA256 서버 키 지문을 서버 관리자의 값과 비교하고 신뢰 여부를 결정합니다.
5. 원격 폴더를 두 번 클릭하거나 주소를 입력해 탐색합니다.
6. 원격 항목을 체크하고 **원격 선택 항목 → 현재 로컬 폴더**, 또는 **로컬 선택 항목 → 원격 폴더**를 누릅니다.

화면에 로컬 대상 경로를 표시합니다. 파일과 중첩 폴더를 양방향으로 복사하며 원본을 삭제하지 않습니다. 같은 이름의 대상은 덮어쓰지 않습니다. 전송이 실패하면 부분 대상이 남을 수 있으며 결과에 경로와 이유를 표시합니다.

비밀번호·개인키 암호는 디스크에 저장하지 않습니다. 신뢰한 서버 키는 `pane-data/ssh-known-hosts.json`에 저장하고 변경되면 연결을 거부합니다.

현재 범위는 **SSH 연결을 통한 그래픽 SFTP 파일 전송**입니다. MobaXterm의 명령어 터미널, X11 포워딩, 점프 호스트, SSH 에이전트·키보드 대화식 인증은 포함하지 않습니다. 원격 연결은 한 번에 하나이며 SFTP에는 일시정지·취소·실행 취소가 없습니다.

## 개발 및 검증

```powershell
npm ci
npm run check
npm test
npm run desktop
npm run build:portable
```

`npm start`는 브라우저 UI 확인용 서버를 실행합니다. 일반 브라우저에서는 실제 파일에 접근하지 않습니다.

추가 검증과 이번 배포의 제한은 [VERIFICATION-0.5.md](VERIFICATION-0.5.md)를 참고하세요. 기존 `DESIGN.md`, `PORTABLE.md`, `VERIFICATION.md`는 0.4 시점 기록이며 현재 사용 방법은 이 문서를 기준으로 합니다.
